6. New findings

REG-001 Average completion accepts a click without a change

Severity: Low. Confirmed functional defect in the added gate, with no arithmetic corruption.

Exact location: S.s5 initial state at line 503; ST[5].bind at line 1233; ST[5].ok at line 1238; prompt at lines 1202–1203.

Actual behaviour: The screen begins with incl7=true and toggled=false. Clicking “Include week 7” again leaves incl7=true but unconditionally sets toggled=true. Continue becomes enabled and advances to the late-weeks screen without showing 4,953 or moving the mean line.

Expected result: If the activity requires a comparison, a click that keeps the current state should not satisfy it. The learner should at least view the excluded-week state as well as the included state initially displayed.

Evidence: Executed the actual binding and navigation handlers. Before click: ST[5].ok()=false. After Include click: incl7=true, toggled=true, ST[5].ok()=true; display remains 4,844. Clicking Continue reaches S.stage=6. The normal exclude/include path also works.

Learner impact: A learner can bypass the intended comparison through an ordinary click on an already-selected control. This does not teach an incorrect figure, but the completion flag overstates what was actually viewed.

Specific correction: Smallest sufficient change: only set toggled=true after an actual exclusion has been selected. Because the included state is initially shown, that ensures both means have been encountered. Alternatively, track a seen-state set. Do not alter the mean calculation.

Confidence: High for the source execution and resulting state. No browser pixel or assistive-technology claim is made.

Suggested local replacement for the state assignment, supplied for review only:

S.s5.incl7 = b.dataset.incl === "1";
if (!S.s5.incl7) S.s5.toggled = true;
draw();
refreshNav();

With that definition, “toggled” effectively means “has viewed the excluded state”. If a full out-and-back action is required instead, track both actions explicitly and update the instruction to match. The app was not edited during the audit.
